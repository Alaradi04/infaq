# INFAQ – AI-Powered Personal Financial Management App

INFAQ is an AI-powered personal finance management application developed to help users manage their financial activities more effectively.

The application helps users track expenses, monitor subscriptions, manage budgets, set savings goals, and gain intelligent financial insights through AI analysis. INFAQ aims to improve financial awareness and encourage better spending habits through a simple and user-friendly experience.

> This project is developed as a Senior Project at the University of Bahrain.

---

## 📌 Project Overview

Managing finances can be difficult due to unclear spending patterns, recurring subscriptions, impulsive purchases, and limited financial awareness.

INFAQ addresses these challenges by providing:

- Expense and income tracking
- AI-assisted financial insights
- Spending pattern analysis
- Budget monitoring and notifications
- Subscription management
- Savings goals tracking
- Sustainability-focused spending insights
- Financial dashboards and summaries

The system combines financial management with AI capabilities to help users make smarter financial decisions.

---

## 🏗 System Architecture

INFAQ follows a layered architecture with AI integration through Supabase Edge Functions.

### Frontend
- Flutter (cross-platform mobile application)

### Backend & Database
- Supabase
  - Authentication
  - PostgreSQL Database
  - Storage
  - Edge Functions

### AI Service
- Gemini API

### AI Integration Layer
- Supabase Edge Functions

> The mobile application communicates with Supabase for authentication and data management. AI requests are securely processed through Supabase Edge Functions, which interact with Gemini API for expense categorization, financial analysis, and insight generation.
